# Проверка явно указанных версий

Подбор новых кандидатов ограничивает оценку до 0.79 при разных явно распознанных словах noir/intense/elixir/absolue либо обозначениях pour homme/pour femme, for men/for women, (муж)/(жен). Одностороннее обозначение — неопределённость, а не доказательство другой или одинаковой версии. Эти слова не удаляются из названия. Противоречивые обозначения аудитории требуют проверки.

Это консервативный ограниченный словарь, не полная база ароматов. MAN внутри названия не переводится автоматически в пол. Уже подтверждённые пользователем локальные алиасы сохраняют прежнюю отдельную логику; механизм не выдаёт новых разрешений на запись.

Новые пояснения добавлены к расширенному режиму разбора. Старый режим include_conditions=False сохранён для прежних журналов.

Официальная коллекция ROJA перечисляет Elysium Pour Homme EDP, Pour Homme Parfum, Pour Femme, Eau Intense и Noir отдельно: https://rojalondon.com/collections/elysium-collection . Источник проверен 03.11.2026. Это подтверждает различие каталожных версий, но не раскрывает, какой вариант подразумевал конкретный поставщик и есть ли крышка у конкретного тестера.
