# Оценка ответа Ginger в основном чате

27 ноября 2026. Продолжение переноса работы агента из отдельного окна в чат.

## Реализовано в коде

После завершённого ответа Qwen появляется компактный раскрываемый блок
«Оценить ответ UNIX». Он доступен и для ответа «нужна ручная проверка».
Пользователь выбирает 0–10, пишет пояснение и сохраняет оценку. Предвыбранного
балла нет. Для действующей оценки доступен отзыв с указанием причины.

Оценка связана с исходным поставщиком, товаром, полным списком кандидатов,
применённым объяснением и полным ответом модели, включая сравнение признаков.
Она не считывает текущую строку Ginger и не переносится на новый товар, если
пользователь переключил прайс. Смена чата, новое сообщение и открытие окна
агента/настроек убирают старый блок. Во время сохранения второй запрос блокируется;
поздний голосовой ввод не запускается параллельно с ним.

Запись использует существующее атомарное хранилище оценок. Повторное сохранение
одного ответа не начисляет новые баллы; отзыв сохраняет исходные данные и
исключает запись из действующих оценок. Ответ Core теперь сообщает, действует
ли оценка: ранее отозванная запись не показывается как восстановленная ни в чате,
ни в прежнем окне агента. После ошибки записи интерфейс не сообщает об успехе;
пользователь может повторить сохранение, защищённое идентификатором содержимого.

Результат сохранения/отзыва записывается в тот же чат с прежней настройкой истории.
Если историю записать не удалось, это отдельное сообщение; уже записанная оценка
не выдаётся за потерянную. У оценки нет доступа к драйверу Ginger, инструментам
агента, выдаче разрешений или изменению весов модели.

## Что проверено

- 70 профильных Python-тестов проходят: оценки и их отзыв, атомарное сохранение,
  история чата, ответы модели, навигация, голос и индикатор Windows 10.
- GingerChat.Smoke проверяет полный исходный ответ, отсутствие оценки по
  умолчанию, допустимые баллы 0/1/10, пустые/недопустимые поля, другой чат,
  закрытый просмотр, двойное нажатие, ошибку записи/отзыва и уже отозванную оценку.
  Сохраняются тесты подготовки и подтверждения одной пары.
- Desktop собирается локально; остаётся прежнее предупреждение CS0649.
- Тесты используют искусственные данные; пользовательские оценки не менялись.

## Ограничения и следующий шаг

Оценка — отзыв о показанном ответе. Она не подтверждает каждый признак, не является
сохранённым уроком и не обучает веса автоматически. Для объяснения, которое будет
влиять на следующие решения, пока остаётся отдельное окно агента с проверкой
понимания и сохранением урока поставщика. Перенос этого процесса в чат — следующий
этап. Просмотр и редактирование всей истории оценок после перезапуска здесь ещё
не реализованы; текущий блок не восстанавливается из текста старого разговора.

На компьютере установлена версия `15c5f0d` (релиз `45905674341`) с подтверждением
пары в чате. Новая оценка в чате требует следующей Windows-сборки. Внешний вид и
реальный пользовательский путь новой оценки ещё не проверены на устройстве из-за
известного ограничения Computer Use. Сопоставления и данные Ginger в этом проходе
не менялись. Ошибка различения Explorer / Platinum / Ultra Blue остаётся отдельной
задачей; высокие оценки не считаются доказательством правильности всех признаков.
