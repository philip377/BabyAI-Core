# Сохранение оценок ответа: 25 ноября 2026

Оценка и её отзыв теперь публикуются только после полной записи JSON и сброса
буфера на диск. Ранее ошибка записи могла оставить обрезанный файл под окончательным
именем: повторное сохранение затем не могло прочитать его.

Временный файл создаётся в том же каталоге. После записи создаётся жёсткая ссылка
под окончательным именем, без замены существующей записи. При ошибке операция
возвращает ошибку; временный файл удаляется. После аварийного завершения процесса
возможен остаточный `.pending`, который не читается как оценка. Файловая система
должна поддерживать жёсткие ссылки (штатный локальный NTFS поддерживает их).
При отсутствии поддержки нет небезопасного перехода к перезаписи.

Проверено на текущем Windows: ошибка сброса записи, ошибка публикации отзыва,
повтор после ошибки и 20 конкурентных сохранений одного ответа. Всего 47 тестов
модели, оценок и команд рабочего приложения проходят.

Это защита сохранности обратной связи, а не обучение весов или разрешение
сопоставлять товары. Уже сохранённые оценки не менялись. Проверка кнопок в реальном
интерфейсе остаётся заблокированной известной ошибкой захвата Computer Use.
