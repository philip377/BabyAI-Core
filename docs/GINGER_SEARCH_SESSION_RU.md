# Связанный шаг поиска и восстановление — 02.11.2026

Испытательный запуск изменения звёздочки теперь после проверки состояния вызывает отдельное чтение двух полных контекстов поиска и формирование отчёта различий кандидатов. До нажатия сохраняется намерение, после него — наблюдаемое состояние. Операция не получает права на сопоставление или запись в каталог.

Восстановление выполняется командой `ginger-search-observe.ps1 -ReceiptDirectory <каталог квитанции>` через Windows PowerShell. Она не активирует окно и не отправляет ввод. Проверяются процесс Ginger, документ, поставщик, выбранная строка, цена, связь, панель, слова, желаемое состояние целевой звёздочки и неизменность остальных фильтров. Два чтения должны совпасть по содержимому. Изменившееся состояние блокирует отчёт, не вызывает повторного нажатия.

Результат observed_stable_needs_review означает только совпадение наблюдений. Даже два одинаковых чтения не подтверждают завершение поиска, отсутствие товара или правильность сопоставления. Лимит чтения — 256 кандидатов; превышение требует уточнения фильтра, не урезания результатов. Каждый отчёт сохраняется отдельно, прежние наблюдения остаются на диске.

Реальная проверка восстановления квитанции выключения l прошла: создан отчёт по двум кандидатам без ввода. Дополнительная попытка нового полного запуска остановилась до создания квитанции и нажатия; причина этого раннего отказа ещё не локализована. Полный связанный запуск на настоящем Ginger пока не объявляется проверенным. Его предел ожидания увеличен до 120 секунд; при неопределённом исходе доступно только чтение состояния.

Проверки: 672 passed, 1 skipped; диагностическая сборка успешна. Тесты покрывают изменение процесса, исходного товара, слова, состояния звёздочки, другого фильтра и кандидатов; пустые результаты не становятся доказательством отсутствия. Следующий этап — диагностировать ранний отказ полного запуска, проверить его от начала до конца и затем расширять до последовательности фильтров. Интеграция с Agent Runtime ещё не завершена.
