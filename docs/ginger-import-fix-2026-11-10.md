# Проверка Ginger: 10 ноября 2026

## Ошибка установленной сборки: причина установлена

Новый журнал выявил ошибку Add-Type: HashSet перенаправлялся в System.Collections.
Ошибка воспроизведена запуском теста компиляции из каталога установленного
приложения: относительные ссылки компилятора подхватывали DLL self-contained
.NET-приложения вместо .NET Framework Windows PowerShell.
Драйвер теперь передаёт абсолютные пути System.dll и System.Core.dll из каталога
текущего Framework. Один и тот же тест до исправления падал, после исправления
прошёл как из установленного приложения, так и из репозитория.
Windows CI теперь повторяет тест из каталога собранного приложения.

Дополнительная проверка чтения живого Ginger завершилась успешно: status=observed,
прочитаны выделенная строка, кандидат и 31 строка прайса. Действий сопоставления
не было. Это подтверждает работу чтения исправленного драйвера, но ещё
не успешность полного автоматического прохода установленного UNIX.

## Предыдущая проверка

Найден и воспроизведён сброс разрешения навигации: загрузка общего
PowerShell-драйвера через Invoke-Expression исполняла его param-блок в области
вызывающего сценария. Переданное ConfirmNavigation=true становилось false.
Это блокировало подтверждённые переходы и изменение фильтров.

Восемь сценариев теперь загружают типы в дочерней области. Проверка
tests/ginger-driver-import-smoke.ps1 компилирует настоящие типы без обращения
к окнам и подтверждает сохранение как выданного, так и отсутствующего разрешения.
Проверка включена в Windows Desktop CI.

Также сохраняются stderr и код завершения неуспешного подпроцесса в локальной
папке сессии. Это позволит установить исходную причину общего Probe failed.
Сохранение диагностической ошибки проверено синтетическим подпроцессом.

Ограничение: первоначальный сбой чтения установленной сборки не воспроизведён
до точной причины. Захват окна через computer-use дважды вернул
SetIsBorderRequired / 0x80004002. Исправление импорта само по себе не доказывает,
что весь проход сопоставления работает. Новых сопоставлений во время этой
проверки не выполнялось; документы Ginger не закрывались и не сохранялись.
