# Проверка без координатного клика

Запуск BabyAI.Desktop.exe --ginger-read-check открывает панель Ginger и один раз
выполняет тот же обработчик чтения, что кнопка «Прочитать прайс».
Разрешение прохода остаётся выключенным. Режим не выбирает кандидата, не
сопоставляет, не сохраняет и не закрывает документ Ginger.

Результат записывается в обычный ginger-actions.log и ginger-sessions.
Повторное открытие панели в том же процессе не запускает проверку снова.
При ошибке действуют прежние ограничения повторов и блокировка сессии.

Это диагностический путь вокруг недоступного координатного ввода инструмента
computer-use на текущей Windows 10. Он не исправляет SetIsBorderRequired в
самом инструменте и не подтверждает работоспособность полного сопоставления.
Следующий этап — запуск режима из установленной сборки и проверка журналов.
