# Отдельная проверка полного названия аромата

Это журнал первоначального этапа. В следующей итерации 27 ноября добавлена передача объяснений поставщика только в извлечение исходного названия. Кандидаты и сравнение имён не получают эти объяснения; требования точных фрагментов и запрет повышения уверенности сохранены. Текущие результаты и ограничения описаны в [журнале уроков](ginger-chat-lessons.md#обозначения-поставщика).

27 ноября 2026. В распознавании без предварительного урока Qwen раньше отмечала identity=match одновременно для Explorer, Explorer Platinum и Explorer Ultra Blue. Исправление не добавляет правила для этих конкретных товаров. Задача разделена на выделение названия и его сравнение.

## Поведение

1. Из каждого кандидата модель выделяет бренд и полное название аромата. Оба поля должны быть точными непересекающимися фрагментами исходной строки, на границах слов. Выдуманные, неоднозначно повторённые или недостающие фрагменты дают неопределённость; неверная схема ответа останавливает запрос.
2. Бренды из кандидатов используются как подсказки для выделения бренда в строке поставщика. Например, подсказка Ex Nihilo помогает модели выделить весь фрагмент «ЕКС нихило», вместо одного «ЕКС». Подсказку нельзя подставить в ответ, если её нет в исходной строке.
3. Отдельный запрос сравнивает только бренд и полное название аромата, с учётом транслитерации. Далее сохраняется прежнее сравнение пяти характеристик товара.
4. Выявленное различие имени исключает кандидата. Неопределённость имени блокирует выбор. Совпадение имени **не повышает** unknown или conflict других проверок до match. Дублирующиеся кандидаты и неоднозначные альтернативы по-прежнему блокируют единственный выбор.

В чате и окне Ginger отображаются выделенные слова и пояснение модели. Это позволяет увидеть неверно разделённый бренд или потерянное слово, а не только итог «название совпадает». Полные данные включены в снимок оцениваемого ответа. Проверка названия сама не выбирает товар и возвращает can_match=false; действия Ginger и разрешения не менялись.

Работа ограничена десятью кандидатами. Повторяющиеся строки используют результат только внутри одного запроса; между строками прайса или поставщиками кэш не переносится. Дополнительные запросы увеличивают время обработки. Уроки и их сохранение/отзыв остаются на прежнем пути: неудачные экспериментальные изменения их интерпретации не включены в эту правку.

## Проверка на настоящей Qwen

Qwen3-8B-Q4_K_M, Vulkan, RTX 2060 SUPER, архивные строки; без действий Ginger, записи уроков и изменения весов.

| Пример | Наблюдаемый результат | Время |
|---|---|---:|
| Mont Blanc Explorer, пять кандидатов | Предложен обычный Explorer 30 ml; Platinum и Ultra Blue получили конфликт полного названия | 18,12 с |
| Тот же список в обратном порядке | Тот же кандидат | 18,65 с |
| Обычный Explorer исключён из списка | Выбора нет; тестер не подставлен | 14,90 с |
| «ЕКС нихило Блю талисман…» | Бренд и аромат выделены верно; все версии Blue Talisman совпадают по имени, но обычная позиция остаётся на проверке из-за tester=unknown | 15,72 с |
| Тот же источник: только другой объём, тестер и Fleur Narcotique | Выбора нет; Fleur Narcotique отличается по названию | 11,97 с |
| Независимый учебный Acme Bloom 50 ml, включая Bloom Night, другой объём и тестер | Предложен обычный Bloom 50 ml | 15,18 с |
| Учебный список без обычного Bloom | Выбора нет | 11,99 с |

Для Ex Nihilo отдельно выполнен тот же запрос через исходный код 77e20fd: все прежние оценки характеристик совпали, включая tester=unknown. Эта неопределённость не вызвана новой проверкой и не была скрыта повышением до match.

Доказательства в локальных outputs: qwen-catalog-scope-probe-20261127-identity-v1.json и qwen-identity-baseline-20261127.json. Это ограниченная выборка. Предложение обычного Explorer не доказывает эквивалентность обозначения Travel Spray любой обычной упаковке; полную пару по-прежнему нужно проверять отдельно.

## Проверки кода и ограничения

100 профильных Python-тестов прошли: извлечение только исходных фрагментов, схемы ответов, неопределённость, ограничение работы, порядок кандидатов, отсутствие общего кэша, сохранение конфликтов и неопределённости остальных признаков, история, оценки, навигация и голос. Локальная Windows Desktop сборка прошла; Windows CI и установщик проверяются отдельно после отправки коммита.

Наличие фрагментов в строке не гарантирует семантически верное разделение бренда и аромата. Это дополнительное свидетельство модели, а не сертификат правильности. Разбор tester/объёма/комплектации остаётся следующим этапом; unknown не следует превращать в match по умолчанию. Новые подписи ещё не проверены через реальный Windows UI. Автоматический проход всего прайса, сохранение урока и полномочия на сопоставление не расширялись.
