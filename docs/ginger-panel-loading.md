# Ожидание панелей Ginger — 22 ноября

В реальном Ginger открыт прайс Альянс №108774, затем экспериментальным визуальным драйвером выбрана вкладка «Сопоставление — новые». Метка распознана однозначно, активный цвет и неизменность документа перепроверены. Это ещё не интегрированный автоматический проход UI UNIX.

Установленная сборка ce4035e при открытии нижних панелей завершилась ошибкой GingerUiBusyException внутри InspectMatching. Повторное действие меню не отправлялось, товары не сопоставлялись.

Исправлены оба пути ожидания: OpenMatching и Prepare. Временно занятый интерфейс допускает повторное чтение в существующем десятисекундном окне, но не повторное открытие меню. Все другие ошибки немедленно передаются вызывающему коду. Проверки документа и исходных строк сохранены.

Локальный тест извлекает оба цикла из рабочих скриптов и проверяет восстановление после временной занятости и немедленный отказ при другой ошибке. Он не взаимодействует с рабочим столом; добавлен в Windows CI. Реальная работа исправления после установки новой сборки пока не подтверждена. Длительность чтения полного списка прайсов остаётся отдельной нерешённой проблемой.
