# Следующая итерация: выключение отдельного фильтра

Драйвер поддерживает желаемое состояние звёздочки: включить или выключить, без слепого переключения и повторного ввода. Команда испытания выключения: `--disable-search-word WORD RECEIPTDIR --confirm-navigation`. Квитанция сохраняет желаемое состояние; при ошибке после записи намерения сохраняется локальный failure.json и автоматический повтор запрещается.

На настоящем Ginger выключен фильтр `l` для прежней третьей строки. MARBERT и 100 остались включены. Список изменился с 0 до 2 кандидатов; отдельное повторное чтение получило обычный Marbert HOMME 100ml и тестер. Эти варианты не признаны совпадением с MAN TOO ash/l. Завершение поиска и идентичность карточки всё ещё не подтверждены; права на связывание не выдаются.

Первая попытка остановилась на проверке текста до нажатия: Ginger разделяет ash/l на ash, /, l. После чтения неизменившегося состояния исправлено сравнение последовательности буквенных, числовых и пунктуационных элементов. Проверки отличающегося объёма и слитых слов остаются строгими. Windows-стенд, диагностическая сборка и проверки диагностического процесса прошли. CI, Windows Desktop и Windows Release Bundle предыдущего коммита cbeb9b1 успешно завершились; текущие изменения требуют нового CI.

Дальше: управление набором фильтров как одной проверяемой последовательностью и явная оценка отличий кандидатов. Это по-прежнему отдельный испытательный запуск, не завершённая интеграция в Agent Runtime.

# Проверка звёздочек поисковых слов — 01.11.2026

Реально проверено в Ginger 4.1.3.92: драйвер включил левую звёздочку у MARBERT в третьей строке прайса 108791. До действия справа наблюдалось 18127 строк, непосредственно после — 0. Повторное чтение подтвердило три включённых слова: MARBERT, l, 100. Пустой результат не доказывает отсутствие товара; завершение поиска не подтверждено.

Действие выполняется только отдельным явно подтверждённым запуском `--enable-search-word WORD RECEIPTDIR --confirm-navigation`. Это испытательный интерфейс, ещё не автоматический цикл Agent Runtime. Уже включённую звёздочку драйвер не выключает. Перед вводом проверяются выбранный товар, соответствие слов его названию, уникальность слова, положение строки, попадание в нужный элемент, переднее окно и масштаб. Изменение геометрии между чтениями блокирует ввод. Поддерживается проверенная геометрия при масштабе 100%; другие условия требуют отдельной проверки.

Намерение сохраняется на диск перед единственным нажатием. После него проверяются состояние звёздочки, неизменность остальных фильтров и выбранного товара. Повторный запуск с тем же каталогом квитанции запрещён, включая случай неопределённого результата. Квитанции и снимки настоящих данных остаются локально. Одновременные испытательные запуски не поддерживаются.

Следующий этап: безопасное управление всем набором слов и проверка обновления результатов. В частности, нельзя объявлять карточку отсутствующей по пустому списку при дополнительных фильтрах. Сопоставление, создание карточек и проведение документов этим испытанием не разрешаются.
