# Время шагов и диагностика остановок

Новые проходы записывают UTC-время начала и длительность каждого действия. Длительность измеряется монотонными часами, а не разницей настенных часов. Итог содержит общую длительность и количество успешно записанных действий. Это измерение текущего пути, не обещание производительности.

При исключении создаётся action-NNN-failure.json: операция, время, длительность и отсутствие разрешения на повтор. Ошибочный ответ контроллера не записывается как наблюдённый результат. Если контроллер завершился с ненулевым кодом, локально сохраняется код и не более последних 16000 байт каждого потока вывода. Эти данные не отправляются на GitHub.

scripts/windows/ginger-batch-report.py --run-directory <проход> --output <новый файл.md> создаёт русский журнал завершённого или остановленного прохода. Он проверяет последовательность действий и не допускает пропавших результатов в успешном проходе. Старым журналам без метрик время не приписывается; отмечается «не измерялось». Незавершённый проход без результата или остановки не экспортируется как завершённый.

Для предыдущего настоящего прохода строк 8–9 сформирован локальный GINGER_PASS_08_09_RU.md. Новые метрики пока проверены на изолированном стенде; реальный экран оставлен пользователю для ручной проверки.
