# Ginger из чата — первая исполняемая цепочка

Это контрольная точка первой версии. Следующее изменение описано в
[подтверждении пары из чата](ginger-chat-confirmation.md).
Свободные формулировки с разбором Qwen добавлены в
[проверке намерения](ginger-chat-intent.md); описание ограниченного распознавания
ниже относится к исходной версии этой цепочки.
Автоматический переход через пустые строки, сохранённый список для разбора и
новые карточки этапов описаны в [продолжении прайса](ginger-chat-deferred.md).

26 ноября 2026. Запрос пользователя: чат — основное управление UNIX; агент
показывает реальные этапы и небольшую анимацию, а не требует цепочки кнопок.

## Реализовано

Фразы «Продолжи сопоставление», «Надо бы продолжить сопоставление»,
«Юникс, давай продолжим сопоставление» запускают подготовку текущей строки.
Поддерживается ограниченное распознавание явных команд, не произвольное понимание
намерения моделью. Вопросы, отрицания и составные команды не запускают эту цепочку.
Обычный чат, голосовой ввод и существующие подтверждения сохраняются.

Вызовы происходят последовательно: захват эксклюзивной сессии → подготовка и чтение
Ginger → существующий план звёздочек при пустом списке → предложение Qwen с учётом
подтверждённого урока поставщика. Защитные проверки драйвера не изменены. В этом
пути нет вызова сопоставления, проведения документа или печати.

Чат сообщает о начале каждого реально запущенного этапа, ошибке, остановке или
получении предложения. Рядом с текущим этапом пульсируют три небольшие точки.
Использованы обычные фигуры и анимация прозрачности, без ProgressRing, который
ранее создавал проблему на Windows 10. При отключённой системной анимации точки
статичны. При завершении, отмене или ошибке анимация останавливается.

Общий «Стоп» отменяет текущую операцию. Ответ модели, пришедший после отмены,
не принимается. Новое задание создаёт новую сессию и заново читает текущий экран.
Отмена в старом окне сопоставления также аннулирует наблюдение: продолжение по
старой строке запрещено. Ошибки смены выделения и занятости Ginger теперь
показываются по-русски, вместо одного кода завершения драйвера.

Результат записывается в тот же чат. При выключенной истории остаётся только
в памяти текущего процесса; при включённой — сохраняется обычным хранилищем.
Запись не вызывает модель, инструменты, обучение или изменение разрешений.
Смена чата до записи приводит к отказу, а не записи в чужой разговор.

## Проверено

- Windows Desktop собирается; прежнее предупреждение CS0649 в AdaptiveUi остаётся.
- GingerChat.Smoke: явные команды и отказ для отрицаний/вопросов; порядок этапов;
  пустой поиск; уже сопоставленная строка; смена товара; остановка после чтения
  и после ответа модели; ошибка драйвера без ложного завершения.
- GingerDiagnostics.Smoke: ошибки, ограничения вывода, таймаут и отмена, отдельные
  русские сообщения о выделении и занятости.
- 42 профильных Python-теста истории, модели, чата и Windows-индикатора проходят.
- Новый тест цепочки добавлен в Windows CI. Реальная цепочка чата и вид анимации
  в Ginger ещё не проверены: известный сбой Computer Use остаётся.

## Следующие этапы, которые не считаются готовыми

Подтверждение и проверяемое сопоставление из чата, оценки и подтверждение уроков
там же; продолжение всего прайса и очереди отмеченных поставщиков; восстановление
навигации из произвольного экрана. Сейчас подтверждение пары и обучение доступны
в существующем окне агента. Из уже сопоставленной строки этот проход дальше сам
не переходит. Исправление понимания Explorer/Platinum/Ultra Blue остаётся отдельной
задачей. Оценки не дообучают веса автоматически.

Сохраняется весь прежний план: питомцы без оконной рамки, настройки агентов,
обучение Qwen, реальная карта памяти, создание товаров, цены/остатки и заказы
с подтверждением проведения/печати. Эта итерация их не заменяет.
