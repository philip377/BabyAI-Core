# Подготовка кандидатов перед предложением модели

26 ноября 2026: пользователь обнаружил, что при пустом списке кнопка предложения
модели многократно выдаёт ошибку про ограниченный список кандидатов. Подготовка
звёздочек была подключена только к автоматическому проходу.

Теперь при пустом списке кнопка сначала вызывает существующий PrepareFiltersAsync
через защищённый Execute: план слов, проверяемые действия драйвера и повторное
чтение. Только после появления кандидатов запрашивается модель. Если поиск пуст
или драйвер остановился, интерфейс сообщает причину без запроса модели.
Сопоставление и разрешения на запись этим действием не выдаются.
Обновление наблюдения также сбрасывает черновик урока от прежней строки.

Проверено: Windows Desktop собирается, 56 тестов планирования фильтров,
предварительных проверок и подготовки строк проходят. Известное предупреждение
CS0649 в AdaptiveUi сохраняется. Реальный сценарий новой кнопки в Ginger ещё
не проверен; ограничения Computer Use остаются. Подготовка использует существующий
план фильтров и не гарантирует нахождение кандидатов для любой строки.

Оценка пользователя 1/10 за ответ Mont Blanc найдена в хранилище оценок вместе с
пояснением о названии аромата заглавными буквами. Это комментарий к ответу,
не сохранённый языковой урок и не обновление весов. Ошибочное сравнение
Explorer с Platinum/Ultra Blue этим изменением не исправлено.
