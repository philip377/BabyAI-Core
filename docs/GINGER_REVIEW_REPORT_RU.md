# Читаемый отчёт проверки Ginger

Локальная команда scripts/windows/ginger-review-report.py принимает --row-directory (журнал строк) и --output (новый файл .md). Она читает проверенную очередь отчётов, сверяет документы и квитанции наблюдений и выводит русское описание каждой позиции. Перед экспортом используется общая блокировка прохода: отчёт не создаётся одновременно с управляемым batch.

В отчёт входят название и цена из исходного прайса, названия наблюдаемых кандидатов, различия и неопределённости. Это сохранённые наблюдения, не свежий запрос Ginger. Цена приводится как исходный текст, без пересчёта и сравнения валют. Неизвестные сведения обозначаются «не указано».

Отчёт не выбирает товар, не выдаёт разрешения на связывание и не доказывает отсутствие товара. Незавершённая навигация и повреждённая очередь блокируют экспорт. Уже существующий файл не перезаписывается. Текст поставщика экранируется, чтобы не превращаться в ссылки или HTML. Скриншоты и реальные отчёты остаются локально, вне публичного PR.
