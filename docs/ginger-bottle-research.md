# Флакон и упаковка: проверка интернет-источников

UNIX собирает фотографии и сведения о флаконе для проверки спорной версии товара. Справка отделена от выбора кандидата и разрешения сопоставления. Она не меняет Ginger, уроки, оценки или веса модели.

## В чате

- `Найди флакон Baldessarini Ambre EDT 90ml` — поиск по явно названному товару, без открытия Ginger.
- После чтения позиции: `Найди флакон`, `Поищи фото флакона`, `Проверь флакон в интернете` — поиск по показанному названию.
- В блоке «Флакон и упаковка» можно исправить публичное название и указать готовую HTTPS-ссылку на страницу. По ссылке поисковик не нужен.

Запрос запускает ограниченную проверку: до трёх страниц, до одной фотографии с каждой. Показаны полные ссылки, время проверки, фотография и проверяемые выдержки. Кнопка «Стоп», смена чата и отмена отбрасывают поздний результат. Прежняя карточка подтверждения пары аннулируется; исследование не расширяет разрешение на привязку.

Фразовый вход пока ограничен описанными просьбами. Это отдельный путь от семантического распознавания команд сопоставления. `Найди флакон` без прочитанного товара просит название. История сохраняет текст и ссылки, но не изображения; фотографии после перезапуска повторно не загружаются автоматически.

## Что передаётся в интернет

Только показанное/явно названное название и поисковые слова `perfume bottle packaging`. Поставщик, цены, остатки, кандидаты, экран и весь прайс не отправляются. Переход по готовой ссылке передаёт сайту её URL; cookies, пароли браузера и учётные данные Ginger не используются.

У команды `ginger.bottle.research` нет доступа к Agent Runtime или драйверу Ginger. Она доступна доверенному Desktop, не входит в каталог инструментов модели. Явный поиск из интерфейса даёт разовое `web.public_read` в существующем PermissionStore; постоянные разрешения не меняются. Прямой вызов без разового согласия требует ранее сохранённого разрешения.

Чтение допускает только HTTPS/443 и публичные IP. Проверяется каждое перенаправление; соединение закрепляется за проверенным IP с TLS-проверкой исходного домена. Локальная/служебная сеть, cookies, прокси, скрипты и активные форматы изображений исключены. Ограничены объём ответа, время и число запросов. Изображения JPEG/PNG/WebP передаются в интерфейс байтами; окно не делает скрытых повторных сетевых запросов по адресам картинок.

## Поисковик и доступность

Базовый адаптер читает [HTML-версию DuckDuckGo](https://duckduckgo.com/duckduckgo-help-pages/features/non-javascript). Это публичная страница с изменяемой разметкой, не гарантированный API. CAPTCHA, неизвестная разметка и HTTP-ошибка считаются недоступностью поиска. Автоматического обхода и повторов нет. Пустая выдача также не доказывает отсутствие версии.

В **Настройки → Интернет-поиск** доступны DuckDuckGo, официальный [Brave Web Search API](https://api-dashboard.search.brave.com/api-reference/web/search/get) и режим «Только по готовой ссылке». Для Brave ключ вводится в отдельное скрытое поле. Пустое поле при сохранении оставляет прежний ключ. Изменения применяются к следующему запросу без перезапуска. Готовая ссылка работает при любом режиме, даже если ключ отсутствует или повреждён.

Ключ защищён [Windows DPAPI для текущего пользователя](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata), записывается атомарно вместе с режимом в `public-search.json` внутри каталога данных Core (`BABYAI_DATA_DIR`, по умолчанию `~/.babyai`). Открытый ключ не записывается в файл, чат, модель, ответы команд или журналы. Передача идёт по существующему приватному каналу Desktop–Core, затем только точному API-домену Brave; перенаправления с ключом запрещены. На других ОС защищённое сохранение недоступно; открытого файлового запасного варианта нет. Удаление сохранённого ключа одновременно включает режим по ссылке.

Сохранение не выполняет сетевой запрос и не означает, что подключение работает. **Проверить подключение** отправляет один показанный запрос `EX NIHILO Blue Talisman perfume bottle`. Проверка не загружает страницы товаров или Qwen и не сохраняет постоянное сетевое разрешение. Есть отмена; смена раздела/закрытие окна отбрасывает поздний ответ. Неуспешный ответ, CAPTCHA, неверный ключ и ограничение запросов показаны отдельно; повторов и скрытого переключения сервиса нет. Некорректный ответ HTTP 200 не считается успешным подключением. Настройка нового ключа не отменяет лимиты и условия выбранного тарифа.

Для совместимости `BABYAI_BRAVE_SEARCH_KEY` используется, когда файл настроек ещё отсутствует, либо выбран Brave без сохранённого ключа. Явно выбранный DuckDuckGo или режим по ссылке игнорирует этот ключ. Повреждённый сохранённый ключ не заменяется ключом из окружения незаметно. На этом ПК реальный ключ не настроен; регистрацию, покупку доступа и проверку настоящего Brave-поиска не выполняли. Ключ следует вводить только в настройках, не в чате или пояснении урока.

Фотографии извлекаются из [Open Graph](https://ogp.me/) либо из существующих изображений страницы с подходящими словами в подписи/адресе. Совпадение слов лишь выбирает справочную картинку. Источник не объявляется официальным автоматически, а содержимое изображения не считается проверенным.

## Доказательства и ограничения

Qwen читает только текст, не фотографии. Принимаются лишь короткие дословные выдержки из загруженных страниц с существующим номером источника и допустимым признаком. Для старого/нового дизайна необходимы слова о физическом флаконе/упаковке и об изменении версии. Маркетинговое `designed as a jewel` про аромат не подтверждает изменение флакона. Некорректный ответ модели отбрасывается, исходные ссылки остаются.

Даже допустимая выдержка требует проверки применимости к конкретному аромату. Не реализованы автоматическое зрительное сравнение фотографий, установление подлинности, хронология всех дизайнов и автоматическое разрешение совпадения по фото. Эти сведения нельзя превращать в подтверждённый урок или награду без пользователя.

## Проверено 27 ноября 2026

- Модульные проверки: ограничения сети и перенаправлений, разовые разрешения, CAPTCHA/пустая выдача, границы запроса, выбор фото, отбрасывание придуманных источников и недоказанных цитат, сохранение длинного запроса в правильном чате.
- GingerChat.Smoke: запросы поиска, привязка ответа к названию, недопустимые ссылки, отсутствие разрешения сопоставления; прежние проверки чата, отмены, подтверждений, оценок и уроков сохранены.
- Настоящий сайт EX NIHILO: прочитана страница Blue Talisman, получено фото флакона. Реальная Qwen3-8B/Vulkan сначала неверно отнесла рекламную метафору к дизайну; добавленная проверка отвергла её, повторный результат не содержит подтверждения старого/нового дизайна.
- DuckDuckGo на этом ПК вернул проверку человека; Baldessarini — HTTP 429. Успешный общий веб-поиск здесь пока не подтверждён. Проверка по доступной ссылке работает.
- Проверка через настоящий Windows UI остаётся незавершённой из-за ранее выявленной ошибки Computer Use; успешная компиляция её не заменяет.
- Настройки проверяются без внешней сети: реальное шифрование/расшифрование Windows, отклонение изменённых защищённых данных, сохранность старых настроек при сбое записи, отсутствие ключа в ответах и трассировке worker, разовое разрешение проверки, отсутствие повторов при 401/403/429/CAPTCHA. Подключение и извлечение страниц используют одни настройки. При остановленном поиске модель больше не загружается зря.
