# Moschino: написание линейки

Добавлен узкий встроенный псевдоним `MOSCHINO CHEAPANDCHIC` → `moschino cheap and chic`. Это нормализация написания, не обучение на объяснении пользователя и не разрешение игнорировать признаки товара.

Проверены совпадение при равных остальных признаках, отказ для другого объёма, концентрации, тестера, vintage, lux, фланкера, пола, другого бренда и дубликатов.

Текущая реальная строка LIGHT CLOUDS пока остаётся на проверку: кандидат содержит «жен», исходное название — нет. Нельзя объявлять сопоставление подтверждённым только на основании исправления пробелов. Нужна проверенная точная пара либо отдельное обоснованное знание об аромате; не удалять пол глобально.
