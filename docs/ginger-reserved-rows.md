# Ранее остановленные попытки

Автоматический проход проверяет существующую защитную запись до изменения
поисковых фильтров. Несопоставленная строка с записью прежней попытки попадает
в очередь ручной проверки; причина выводится в журнал. Проход переходит дальше.
Идентичность сверяется по процессу, таблице, документу, поставщику, позиции и
полному названию — тем же полям, которые сохраняет драйвер записи.

Записи не удаляются и не изменяются. Эксклюзивная проверка непосредственно
перед записью остаётся обязательной. Повреждённые записи останавливают проход.
Ручной запуск сопоставления также не получает права обойти защитную запись.

Тесты проверяют найденную запись, независимую следующую строку, другой документ,
сохранность истории и отказ при повреждении. Полный автоматический проход
установленного приложения с этой доработкой ещё не проверен.
