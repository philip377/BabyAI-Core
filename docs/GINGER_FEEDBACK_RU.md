# Пояснения пользователя к кандидатам Ginger

Подготовлена отдельная локальная HTML-форма для сохранённых отчётов. Она не встроена в основное окно UNIX и не меняет его интерфейс, голосовой ввод, VAD, Agent Runtime или разрешения.

## Как пользоваться

1. Открой index.html из подготовленного каталога формы в своём браузере.
2. Для нужного кандидата выбери «Подходит по моему мнению», «Не подходит» или «Не уверен». Для первых двух ответов напиши причину: объём, версия, тестер, комплектация или другое различие.
3. Если кандидатов нет или данных мало, выбери для строки «Нужен другой поиск», «Пропустить» или «Не уверен» и добавь пояснение.
4. Нажми «Скачать мои пояснения» и пришли полученный JSON-файл в текущую задачу. До скачивания введённый текст существует только на странице; закрытие страницы его потеряет.

Ранее скачанный файл можно выбрать в поле «Продолжить с ранее скачанного файла пояснений». Форма сверит принадлежность к тому же набору наблюдений и восстановит ответы; файл другой проверки не заменяет текущие ответы.

Не требуется проверять всё сразу: нетронутые позиции при импорте игнорируются. Пояснения относятся только к показанным наблюдениям. Они не являются общим правилом, разрешением связать товар или подтверждением его идентификатора. Применение новых общих бизнес-правил остаётся отдельным будущим этапом.

## Что реализовано

Экспорт: scripts/windows/ginger-review-form.py --row-directory <журнал> --output-directory <новый каталог>. Создаёт index.html и bundle.json. Форма работает без сервера и сетевых обращений. Тексты выводятся как текст, JSON экранируется; политика страницы запрещает внешние подключения и отправку форм.

Импорт: scripts/windows/ginger-review-feedback.py --row-directory <журнал> --bundle <bundle.json> --feedback <скачанный файл>. Перед записью сверяет отпечатки исходных отчётов, номера и названия кандидатов, ограничивает размер и длину пояснений, отвергает неизвестные поля и попытки передать разрешения. Обе операции используют блокировку управляемого прохода.

История хранится рядом с журналом в каталоге .feedback, отдельными неизменяемыми записями с цепочкой контрольных сумм. Повторный импорт того же содержания идемпотентен; изменённое мнение добавляется новой записью. Записи имеют статус annotation_only, can_write=false, can_match=false, rules_applied=false. Цепочка — проверка целостности локальных файлов, не цифровая подпись личности автора.

## Проверка и ограничения

Проверены парсер, неверные и устаревшие ссылки на кандидатов, отсутствие обязательной причины, повторный импорт, повреждённая история, экранирование и запрет перезаписи формы. Сценарий JavaScript от выбора ответа до JSON проверен отдельным модульным стендом без браузера; JSON принимается тем же импортом.

Визуальная проверка в браузере не выполнена: инструмент браузера запретил локальный file URL. Ограничение не обходилось. Форма не отправляет пояснения в UNIX автоматически: требуется скачивание и явный импорт. Пользовательских ответов пока нет, реальные отзывы не создавались. Существующие отчёты и экран Ginger не изменялись.
