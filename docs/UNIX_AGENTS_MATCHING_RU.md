# Агенты и сопоставление Ginger — интеграция

Раздел «Агенты» содержит локально сохраняемый список. Можно создавать, переименовывать и удалять собственные профили, задавать специализацию и цвет питомца. Задача профиля идёт через существующий чат UNIX с прежними разрешениями. Создание профиля не создаёт независимый фоновый процесс.

Питомца можно вывести кнопкой или перетаскиванием имени. Его собственное окно перемещается за заголовок и лицо, положение сохраняется. В настройках доступны анимация, тихий режим и скрытие в полноэкранных приложениях. На время взаимодействия с Ginger питомцы скрываются. Закрытие питомца не отменяет задачу.

## Работа с прайсом

1. Открой Ginger Agent и прочитай текущий прайс на вкладке «Сопоставление — новые».
2. Панель показывает полное название поставщика и выбранного кандидата.
3. Для одной пары выбери кандидата и поставь подтверждение. Можно записать объяснение и разрешить эту точную пару в следующих проходах у того же поставщика.
4. Для автоматического прохода отдельно разреши работу с показанным прайсом. Применяются точные совпадения признаков либо ранее разрешённые точные пары. Остальные позиции остаются на ручной проверке.
5. «Стоп» прекращает следующие действия. Уже отправленное сопоставление сначала проверяется; двойной клик не повторяется при неизвестном результате.

Перед сопоставлением проверяются весь наблюдавшийся прайс, выделенная строка, активный синий цвет, кандидат, геометрия и отсутствие перекрытия. После действия перечитывается вся таблица; допускается изменение только нужной связи. Документ не закрывается и не проводится. Прямых запросов к SQL/серверу нет.

Обучение хранит решения по точным названиям и поставщику. Объяснение сохраняется для проверки, но не превращается автоматически в общее правило для других товаров. Разрешение пары можно отозвать в настройках; история остаётся.

## Границы текущей реализации

- Панель управляет текущим открытым прайсом; полный запуск Ginger, авторизация и переход по всем включённым прайсам пока не объединены с этой панелью.
- Поиск по звёздочкам использует существующий проверяемый планировщик. Похожие названия и неподтверждённые варианты отправляются на ручную проверку.
- Интернет-проверка старого/нового оформления пока не является автономным действием агента.
- Питомцы представлены небольшими окнами; прозрачная поверхность и собственные изображения ещё не реализованы.
- Создание карточек, заказов, проведение и печать не входят в этот проход.
- Для установки нужна полная Windows Release Bundle: она содержит Python, модель STT и локальный runtime. Обычный Desktop artifact не заменяет установщик.

Локальные сессии: `%LOCALAPPDATA%/BabyAI/ginger-sessions`. Профили: `agents.json`. Обучение: `ginger-learning`. Неизвестный результат сопоставления требует проверки сохранённых наблюдений, а не повторного запуска клика.
