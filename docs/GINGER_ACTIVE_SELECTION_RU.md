# Активное синее выделение перед сопоставлением

Уточнение владельца: перед двойным кликом по кандидату исходная позиция прайса должна иметь синее, а не голубое выделение.

Контроллер сначала сверяет весь прайс и выбранную позицию, сохраняет намерение фокусировки и повторно выделяет эту же ячейку названия через интерфейс доступности. Затем проверяет активное окно, масштаб, геометрию ячейки и отсутствие перекрытия другим окном. Цвет считывается с экрана в 32 точках внутри верхней и нижней полосы ячейки. Требуется минимум 70% активного синего; голубой RGB(173,216,230) отклоняется. Цвет не заменяет проверку идентичности позиции. Неподдерживаемая тема/неясные пиксели блокируют ввод.

Проверка повторяется внутри метода сопоставления непосредственно перед отправкой двойного клика. Остальные проверки источника, списка кандидатов, попадания в кандидата и журнал однократного действия сохранены.

Проверено интерактивно на тестовой форме: фактическая голубая заливка блокируется; активная синяя допускается; после неё возникает ровно одно событие двойного клика по нужному тестеру. Полный Windows smoke-тест завершился успешно.

Первое сопоставление L’Artisan подтверждено пользователем. Новый журнал продолжения создан на строке 11 после точного сравнения всех 28 строк и выделения с квитанцией успешного сопоставления. Связь с предыдущей квитанцией сохранена в отдельном файле рядом с журналом, старые события не изменены.

Строка 11 ARMANI ACQUA di GIOIA edp 100 ml (немного подмят) прочитана, 9 кандидатов сохранены в веб-проверке outputs/ginger-review-armani. Нового сопоставления в Ginger в этой итерации не выполнялось. Правило обращения с пометкой о состоянии не предполагается автоматически.

Изменения локальные; новая публикация и Windows CI в этой итерации не запускались.
